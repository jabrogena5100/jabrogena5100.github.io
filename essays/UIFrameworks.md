## UI Frameowrks: Do or Flop
**What is a UI Framework?**

Before talking about why we need UI frameworks, we first have know what they are to begin with. For starters, UI is built off of HTML, CSS, and Javascript. HTML provides the semantics of a website, CSS provides designs, and Javascript provides interactivity with the DOM. However, since these are the basic building languages of websites, we can infer that they also incur several bugs because we have to constantly rebuild things. This is where a UI framework like Bootstrap comes in. Bootstrap takes away the repetitiveness of building componenents and gives pre-built ones for us (such as buttons, modals, dropdowns, and navbars) so that we can focus on displaying CRUD data on the user interface. 

**Why Bother Using a Framework Like Bootstrap?**

We use a UI framework like Bootstrap as a means to efficiently build layouts of websites. By this, we are able to lessen the amount of mistakes and bugs that occur. There are more UI frameworks like Bootstrap that does it better such as other component frameworks like MaterialUI. Because you need to also download components or utilities (even unnecessary ones) when you need to use Bootstrap, you also will take up a lot more memory, so MaterialUI optimizes this. 

**What Does One Get in Return for the Time and Investment?**

A user of a UI Framework would mean they are able to use pre-built components and not have to reinvent the wheel for every new project. Some frameworks provide Accessible Rich Internet Applications (ARIA) for people to navigate websites more ergonomically. Because these frameworks have documentation, people most likely encountered the same issues/bugs that you're facing, and so you are able to find answers quickly. The documentations do a good job of educating how to use such frameworks. One thing to note, however, is that you when using a framework like Bootstrap, that means you get the Bootstrap look, which is notable for its distinct look that is applied to a lot of websites. 

**My Experience with Bootstrap**

My experience with Bootstrap is that it can be hard to utilize such components (like navbars) if you still don't have a good grasp of CSS spacing. I think I still am working on it, but it's fundamentally CSS but with the added layer of using it as class attributes within HTML. I especially like being able to use pre-defined components/styles and not have to worry about creating lots of <div>s in order to create CSS components. I would rather be pragmatic and build a website by focusing more on business logic than the layout of my pages. Overall, I still am learning the framework and also how to build beautiful websites.
