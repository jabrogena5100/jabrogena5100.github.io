## I. Introduction

Artificial intelligence (AI) has begun to transform traditional education as we know it. A major breakthrough in modern AI came with the 2017 paper _Attention Is All You Need_, which introduced the Transformer architecture and fundamentally changed how neural networks process language. Unlike traditional feed-forward neural networks, which learn by adjusting initialized weights based on gradients calculated through backpropagation, Transformers use a mechanism called self-attention to identify and strengthen relationships between different tokens, such as words, within a sequence.

One of the most influential applications of this architecture has been OpenAI's Generative pre-trained Transformer (GPT) series. In 2020, OpenAI released GPT-3, a decoder-only Transformer architecture. Two years later, ChatGPT would release under version 3.5 and was known for language generation, question-answering, and serving as a coding assistant. Since then, ChatGPT have retrained their initial version with their current model giving us GPT-5 along with other AI assistants such as Google Gemini and Anthropic Claude. Students have learned to incorporate these AI applications with their learning.

In ICS 314, I mainly used ChatGPT as my main AI tool. I used it as a personalized learning assistant to help me understand assignment instructions and project workflow. I've used it as an AI-assisted coding tool for tasks such as installing services, library-specific syntax lookups, and general software development purposes.

## II. Personal Experience with AI:

1. **Experience quizzes**

In E18, I used it to help me look up the functions that I should use because the ones shown on the websites and videos were outdated. For example _.each(arr,fn) translates to arr.forEach(fn) in native JavaScript/TypeScript and _.reduce(arr,fn, initial) translates to arr.reduce(fn, initial).

1. **Practice quizzes**

In E34 and E35, I used it to help me download bootstrap and to help me look up syntax instead going back and forth between VS Code and the Bootstrap documentation.

1. **Quizzes**

In Quiz Number 3: Mauna Loa Cities, I used AI summarize the given instructions. Then I used it to help me structure the given data into a readable format.

1. **Essays**

In all of my essays, I used AI mainly to help me correct my grammar after I have written everything out myself. This could be from spelling mistakes, tense inconsistencies, and parallelity errors.

1. **Final project**

For the final project, I used it to help me make CRUD functions, identity which files should I make "client" or "server", and implement clever styling using react-bootstrap.

1. **Learning a concept / tutorial**

The concept that I had trouble with was about async functions because we didn't really go over them in class. So when I asked how these functions worked, I learned what an event-listener is, timeouts, and the difference between blocking and non-blocking.

1. **Answering a question in class or in Discord**

If I remember correctly, someone was having a problem with installation issues and because I didn't have that problem, I wouldn't find any useful results if I tried asking AI.

1. **Asking or answering a smart-question**

I didn't ask a smart question. The only smart-question that I answered was when someone asked for help with an npm command and I responded with they're probably in the wrong directory. Even then I didn't use AI.

1. **Coding example**

I used it to explain the use cases of .reduce, .filter, and .map because they were the most important ones in the functional programming experiences.

1. **Explaining code**

One time I used AI to explain code was with async functions. It explained how it's used for querying database, sending API requests, and loading data into the frontend.

1. **Writing code**

I used AI to create the skeleton code for quizzes and my final project. I also used it to make code look better than what I've written and also get help with fixing installation problems.

1. **Documenting code**

I used AI to help me with the GitHub Pages homepage for my final project in rewording what I've already written and add more stuff that I've missed.

1. **Quality assurance**

One issue that I had with ESLint error was with Card.Body. AI suggested that I redownload React-Bootstrap and reinstall my packages through package.json, but the error is still there so this is one of the cases that AI didn't solve the problem.

1. **Other uses in ICS 314 not listed**

One thing that's not listed is explaining the instructions of the several experiences. I found that using AI means it breaks the steps that you need to do in a more compact format.

## III. Impact on Learning and Understanding:

The incorporation of AI has drastically influenced my learning experience. At times when I would code, I often run into a roadblock so I ask AI to help me code better. Not only does it give me suggestions but explains the limitations of my code and why its solution is better than mine. Because of the asynchronous format of this class, I learned a lot with the help of AI in comprehension, skill development, and problem-solving abilities. AI was useful for helping me understand software engineering concepts and it also helped me to understand scenarios when it's best to not use AI. I found that the skills that I applied in assignments built on the stuff that AI helped with. In retrospect, AI made up a big percentage of the resources that I used in this class alongside the experiences.

## V. Challenges and Opportunities

AI does code better than me, there's no doubt about that. The challenges that I had with AI only occurred when I would give a fresh prompt and we have to go back and forth to solve the problem. For example with version issues, the AI would ask questions about why am I using NextAuth.js version 4 instead of version 5 or am using an outdated version of prisma when there's a new one. So I think the hard part is that since every assignment has outdated versions of the tools we need to use, I constantly have to inquire AI about how to update them. Just like how the assignments build on knowing the tools from previous assignments, a chat with AI can seem like, in the first part, we have to start the important installations first and then I will be able to answer your question, if that makes sense.

Some potential opportunities for further integration of AI in software engineering education is serving as a guide for new ideas thereby making you more efficient, more proactive, and much better at producing code in general. So AI can serve as your aid when brainstorming for new ideas. This especially helped me when I was reading over the Final Project ideas. Initially, I thought a lot of these sound pretty nice because they almost have the same requirements which are to incorporate CRUD, use auth for logging in / signing up, and having a database. So I asked ChatGPT how would I create a gym scheduling app and what some of the things needed are. So overall, ChatGPT is good for exploring new ideas, along with helping with code of course.

## VI. Comparative Analysis

Traditional teaching methods include going to lectures, reading textbooks, and watching videos to learn new things. Meanwhile AI-enhanced approaches combine these methods but shifts them a great amount towards AI assistants such as ChatGPT, Google Gemini, or Claude AI. With traditional teaching methods, I feel that it's still very good for learning what the new things are. For example, if I haven't heard of async functions before then I could go to YouTube to explain it. On the contrary, if I need more practice and want to hammer a concept down, then AI can absolutely help with this. AI lets you engage with it meaning you can ask all the questions you want and it will answer you. Both methods, traditional and AI, will help with knowledge retention and practical skill development. I also think having many different resources is good because they provide different explanations.

## VII. Future Considerations

The future role of AI in software engineering education is that it will drastically improve how people will code now. There's a term called vibe-coding so that means anyone can tell AI to make a fully functional application and have it run. For example, you can create a multiplayer game just using AI. I still think knowing how to use create classes, functions, type-casting is important to become a well-rounded software engineer. Some potential advancements are that there would be better produced code and less bugs. Some challenges are that there will be many software engineers who primarily use AI without knowing the basics so they rely too much on AI. One area of improvement could be that there should be different levels of coding-assisted AI. For example, you can have one that's beginner level and one that's completely a master at coding so that you can make full good use of it.

## VIII. Conclusion

Overall, AI has become a valuable tool in software engineering education, especially through its ability to provide guidance, explain concepts, and assist with coding. Throughout ICS 314, I used AI for a variety of purposes, including understanding assignment instructions, practicing concepts, writing and explaining code, and improving my essays. While AI can sometimes struggle with outdated libraries, installation issues, or problems that require more context, it is still a useful resource when used alongside traditional learning methods. I believe the most effective approach is not to rely completely on AI, but to use it as an assistant while still developing a strong understanding of fundamental programming concepts. As AI continues to improve, it becomes more important for students to learn how to use these tools effectively to become better software engineers.
