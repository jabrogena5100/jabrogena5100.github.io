## TypeScript is better than JavaScript, to say the least

**TypeScript is better than JavaScript, to say the least**

In the grand scheme of things, I think TypeScript is a great programming language that outmatches its sister JavaScript. It's static-based typing which means types such as strings, booleans, numbers makes the code-base more stable. It also runs at compile time rather than run-time, which means there will be more robustness. Because it's static typing, it manages large amounts of complex data that can serve programs that keep on expanding.

## JavaScript has sort of the same syntax as C and Java

Since 'engineering' comes after computer and not 'science', we are expected to know more about low-level programming, which has Object-Oriented Programming alignment. Prior to this class, I had no experience with JavaScript, so I was skeptical but now I know that it's heavily influenced by C, which is the same for TypeScript. The differences between TypeScript and C are that TypeScript has more leeway with syntax errors like forgetting to put in a semicolon, not declaring a type, and having anonymous functions. Furthermore, the notation of objects was significantly different than what I'm used to in Java and C. Here, JSON and Markdown plays a larger role while in C, it has to do more with the usage of 'Object-Oriented Programming' fundamentals.
